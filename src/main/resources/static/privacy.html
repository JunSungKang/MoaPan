로그인회원가입

개인정보 처리 안내 · 검토용 초안

이름·이메일·전화번호를 받지 않으며, 관심사 설정은 현재 브라우저 안에 저장합니다.

서버는 계정 UUID, 정규화 아이디, 비밀번호 해시, 활성 상태·권한, 인증 세션, 호출량 제한용 최소 카운터를 처리합니다. 비밀번호 평문은 저장하지 않습니다. 계정 운영 데이터도 회원 관련 정보입니다.

관심 문장·태그 가중치·검색어·열람·클릭·체류시간을 서버나 외부 AI에 전송·저장하지 않습니다. 문장 원문은 태그 확인 후 폐기합니다. 기사와 보안 토큰은 브라우저 영구 저장소에 보관하지 않습니다.

세션은 유휴30분·절대12시간에 만료합니다. 호출량·인증 카운터는 짧은 운영 기간 이후 정리합니다. 탈퇴 시 계정·세션·연결 카운터를 삭제하며 현재 브라우저의 설정도 삭제합니다.

브라우저 설정은 계정별로 분리하지만 같은 기기 프로필 접근자에게 암호학적 비밀성을 보장하지 않습니다. 다른 기기 동기화와 이메일·전화 복구는 없습니다. 브라우저 데이터 삭제 시 관심사도 사라집니다.

외부 분석 SDK·광고·추적 픽셀은 사용하지 않습니다. 연결을 위해 IP가 일시 처리되지만 회원별 IP·User-Agent 이력을 기록하는 기능은 없습니다. 배포 사업자의 실제 로그 정책과 백업 보관·운영자 연락 경로는 사업 개시 전에 확정해야 합니다.

소개·출처개인정보 안내이용약관 초안원문 이동 후의 정보 처리는 원문 사이트 정책에 따릅니다.
