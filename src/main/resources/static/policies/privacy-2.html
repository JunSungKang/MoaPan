약관 개정 제 2판

이름·이메일·전화번호를 받지 않으며, 관심사 설정은 현재 브라우저 안에 저장합니다. 계정과 인증 정보를 처리하므로 완전한 익명 서비스는 아닙니다.

1. 서버에서 처리하는 정보와 목적

회원이 입력하는 정보는 아이디·비밀번호입니다. 비밀번호는 Argon2id 해시로 저장하고 원문을 보관하지 않습니다. 계정 UUID, 정규화 아이디, 비밀번호 해시, 활성 상태, 권한을 계정 제공·인증에 사용합니다. 세션과 최소 제한 카운터를 로그인 유지·오남용 방지에 사용합니다. 신규 가입 시 동의한 약관 버전과 서버의 동의 시각을 저장하며 동의 증빙용 IP·기기 지문을 추가 수집하지 않습니다.

이는 가입·서비스 제공과 보안에 필요한 처리입니다. 별도의 광고·마케팅 이용 동의를 요구하지 않습니다. 회원 관심사·검색어·열람·클릭·체류시간을 서버에 저장하지 않습니다.

2. 보유와 삭제

계정 정보와 약관 동의 기록은 탈퇴 시 삭제합니다. 세션은 유휴 30분, 절대 12시간으로 제한하며 만료 세션을 정리합니다. 로그인 실패 식별자는 keyed HMAC으로 처리하며 제한 카운터는 용도별 짧은 만료 기간 후 정리합니다. 뉴스 제한 카운터의 최대 유효기간은 48시간이며 기사별 열람 이력을 포함하지 않습니다.

수동 암호화 백업의 보관기간은 7일이며 자동 백업은 구성하지 않았습니다. 복원 시 모든 복원 계정을 비활성화하고 세션을 제거하여 탈퇴 계정이 자동 재활성화되지 않도록 합니다. 백업은 Git이나 공개 산출물에 포함하지 않습니다.

3. 브라우저에만 저장하는 정보

계정 UUID별 IndexedDB에 관심 태그·가중치·제외 목록·설정 버전을 저장합니다. 관심 문장은 브라우저에서 태그를 추출하고 확정한 뒤 폐기합니다. 설정은 브라우저를 종료해도 남지만 다른 기기로 자동 동기화되지 않습니다. 설정 화면에서 초기화·삭제할 수 있습니다. 브라우저 데이터를 지우면 설정도 사라집니다.

로그아웃 시 기사 화면과 메모리를 비웁니다. 탈퇴 시 현재 브라우저의 해당 계정 설정도 삭제하며 다른 브라우저는 다음 인증 실패 시 정리합니다. 오프라인 기기의 즉시 삭제나 같은 브라우저 프로필에 접근하는 사람에 대한 암호학적 비밀성을 보장하지 않습니다.

4. 쿠키·로그·외부 연결

인증에 Secure·HttpOnly·SameSite 세션 쿠키를 사용합니다. CSRF 토큰은 JavaScript 메모리에만 보관합니다. sessionStorage에는 현재 계정 식별용 UUID만 저장하며 관심사 저장소로 사용하지 않습니다. 비밀번호·쿠키·요청 본문·검색어를 로그에 기록하지 않습니다. 통신에는 IP의 일시 처리가 필요하지만 회원별 IP·User-Agent 접근 이력을 저장하는 기능은 없습니다.

외부 광고·분석 SDK·추적 픽셀·원격 폰트를 사용하지 않습니다. 개인 관심사를 외부 AI에 보내지 않습니다. 원문 링크를 열면 원문 사이트의 정책에 따라 정보가 처리됩니다. 외부 사업자의 모든 로그 정책까지 보증하지는 않습니다.

5. 이용자의 제어와 문의

로그인 후 설정에서 비밀번호 변경·탈퇴·로컬 관심사 삭제가 가능합니다. 이메일·전화번호를 받지 않으므로 비밀번호 분실 복구는 제공하지 않습니다.

운영자 및 개인정보 문의 연락처는 아직 등록되지 않았습니다. 운영 주체가 실제 정보를 확정하여 게시해야 하며, 현재 문의 접수에는 제한이 있습니다. 이 문서를 법률 검토 완료본으로 표시하지 않습니다.
