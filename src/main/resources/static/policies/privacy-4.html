약관 개정 제 4판

모아판은 가입과 서비스 제공에 필요한 정보만 처리합니다. 이름·이메일·전화번호는 받지 않으며, 관심사 설정은 모아판으로 보내지 않고 현재 브라우저에 저장합니다.

1. 어떤 정보를, 왜 사용하나요?

  • 아이디와 비밀번호: 회원가입과 로그인에 사용합니다. 비밀번호는 원래 값을 알아볼 수 없는 형태로 바꿔 보관합니다.
  • 계정 관리 정보: 회원을 구분하는 내부 번호, 계정의 이용 가능 여부, 일반 회원·관리자 구분을 계정 운영에 사용합니다.
  • 로그인 유지 정보: 로그인한 상태를 유지하고 본인 계정으로 서비스를 이용하도록 하는 데 사용합니다.
  • 보안용 횟수 정보: 로그인 실패 횟수와 뉴스 요청·제공 수량 등을 일시적으로 보관해 무단 접속과 과도한 이용을 제한합니다. 어떤 기사를 읽었는지는 기록하지 않습니다.
  • 약관 동의 기록: 동의한 약관과 동의한 날짜·시간을 가입 확인에 사용합니다.

관심사, 검색어, 기사 열람·클릭 내역, 머문 시간은 모아판에 전송하거나 저장하지 않습니다. 회원정보를 광고나 마케팅에 이용하지 않습니다.

2. 언제까지 보관하고 어떻게 삭제하나요?

  • 계정 정보와 약관 동의 기록: 탈퇴할 때 삭제합니다.
  • 로그인 유지 정보: 30분 동안 이용하지 않거나 로그인한 지 12시간이 지나면 만료됩니다. 로그아웃하거나 탈퇴하면 로그인 상태가 해제됩니다.
  • 보안용 횟수 정보: 목적별로 정해진 짧은 기간이 지나면 정리합니다. 로그인 실패 횟수는 15분, 뉴스 이용량 제한 정보는 최대 48시간 동안 유효합니다. 계정에 연결된 제한 정보는 탈퇴할 때 삭제합니다.

탈퇴한 계정은 서비스에서 삭제합니다. 장애 복구를 위해 별도로 만든 백업에 정보가 남아 있는 경우에는 최대 7일 동안 보관합니다. 백업은 잠금 처리해 보관하며, 복원하더라도 탈퇴 계정이 자동으로 다시 사용 가능해지지 않도록 관리합니다.

3. 관심사 설정은 어디에 저장되나요?

선택한 관심 주제, 관심 정도, 제외한 주제·출처는 현재 기기의 브라우저에 계정별로 저장됩니다. 입력한 관심 문장은 이 브라우저 안에서만 분석하며, 주제를 확인해 적용하면 문장은 지웁니다.

브라우저를 닫았다 열어도 설정은 유지됩니다. 다만 다른 기기나 브라우저로 자동으로 옮겨지지 않으며, 브라우저의 저장 데이터를 지우면 설정도 삭제됩니다. 설정 화면에서도 직접 초기화하거나 삭제할 수 있습니다.

원하면 관심사 설정을 비밀번호로 잠근 파일로 내보내 다른 기기로 옮길 수 있습니다. 파일에는 관심 주제·관심 정도·제외 설정과 계정을 구분하는 내부 번호가 담깁니다. 파일 생성과 열기는 브라우저 안에서 이루어지며 파일과 파일 비밀번호는 모아판에 전송하지 않습니다. 파일을 직접 전달하는 데 다른 서비스를 이용하면 그 서비스의 정책도 확인해 주세요. 내보낸 파일은 브라우저 설정 삭제나 탈퇴로 지워지지 않으므로 직접 삭제해야 합니다.

로그아웃만으로 관심사가 지워지지는 않습니다. 공용 기기에서는 이용을 마치기 전에 설정 화면에서 브라우저에 저장된 개인화 데이터를 삭제해 주세요. 같은 브라우저를 함께 쓰는 사람에게 설정이 노출될 수 있습니다.

탈퇴하면 현재 브라우저에 저장된 해당 계정의 설정도 삭제합니다. 다른 브라우저에 남은 설정은 다음에 접속해 로그인 상태를 확인할 때 정리합니다. 인터넷에 연결되지 않은 기기의 설정까지 즉시 지울 수는 없습니다.

4. 쿠키와 접속 정보

쿠키는 웹사이트가 브라우저에 저장하는 작은 정보입니다. 모아판은 로그인 상태를 유지하는 데 필요한 쿠키를 사용합니다. 브라우저 설정에서 쿠키를 차단하거나 삭제할 수 있지만, 차단하면 로그인 등 일부 기능을 이용할 수 없습니다.

인터넷 통신에는 접속 주소 등의 일시적인 처리가 필요합니다. 모아판은 이를 회원별 접속 이력이나 광고 추적 기록으로 쌓아 두지 않습니다. 비밀번호나 관심 문장을 서비스 오류 기록에 남기지 않습니다.

5. 외부 서비스와 연결되는 경우

모아판은 광고 추적 도구를 사용하지 않으며, 관심사나 검색어를 외부 인공지능 서비스에 보내지 않습니다.

원문 링크를 누르면 해당 뉴스 사이트로 직접 이동합니다. 이동한 사이트의 정보 수집과 이용에는 그 사이트의 개인정보 처리방침이 적용됩니다.

6. 내 정보를 관리하는 방법

로그인 후 계정 관리에서 비밀번호를 바꾸거나 탈퇴할 수 있습니다. 관심사 설정에서는 주제를 수정·삭제하거나 다른 기기로 옮길 수 있습니다. 비밀번호를 잊으면 이메일이나 전화번호로 계정을 복구할 수 없으니 안전하게 보관해 주세요.

개인정보의 열람·정정·삭제·처리 정지를 요청할 수 있습니다. 다만 운영자명과 개인정보 문의 연락처가 아직 등록되지 않아, 설정 화면에서 제공하지 않는 요청을 접수할 공식 창구는 현재 없습니다. 연락처가 확정되면 이 페이지에 안내하겠습니다.

7. 이 안내가 바뀌는 경우

개인정보 처리 내용이 바뀌면 변경 내용과 적용일을 안내합니다. 이번 수정에는 사용자가 직접 관심사 파일을 옮기는 방법을 추가했습니다. 모아판 서버가 수집하는 정보나 이용 목적은 늘리지 않았습니다.
