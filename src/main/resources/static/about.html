서로 다른 출처, 하나의 지면

여러 출처의 뉴스를 관심사에 맞게 모아 종이신문처럼 읽는 개인화 뉴스 서비스입니다. 관심사는 서버로 보내지 않습니다. 로그인 후 대표 관심사 지면을 읽거나 자신의 관심사를 적용할 수 있습니다. 제공받은 제한된 후보 안에서 브라우저가 정렬합니다.

출처와 요약

자동 요약은 이용이 허용된 설명문에서 문장을 추출합니다. 부족하면 원문을 안내하며 번역하지 않은 자료는 원문 언어로 표시합니다. 자동 처리가 정확성을 보장하지 않습니다. 각 기사에서 출처와 원문 링크를 확인하세요.

출처의 등록·권리 승인은 기술 점검과 별도입니다. 검토된 출처만 공개 대상으로 사용합니다. 사진과 기관 로고는 복제하지 않습니다.

한국어·영어로 제공되는 제목과 요약에는 자동 번역이 포함됩니다. 번역은 원문의 뜻과 다를 수 있으니 중요한 내용은 원문을 확인해 주세요.

V1 검증 상태

기술·보안·외부 배포 검증은 진행 중입니다. 상표·도메인·사업자등록·언론 관련 등록·법률 검토가 완료되었다는 뜻이 아닙니다.

연구·보안 자료 출처

arXiv 자료는 논문 제목·초록 등 CC0 메타데이터에서 추출합니다. 사전 공개 논문은 동료 심사가 완료되지 않았을 수 있으며 성능 수치를 모아판이 재현 검증한 것은 아닙니다. 전문은 원문 링크에서 확인하세요.

보안 공지 출처: GitHub Advisory Database · CC BY 4.0. 요약은 원문에서 추출·축약한 것으로 출처의 공식 편집물이나 제휴를 뜻하지 않습니다.

소식에서 다음 연구로

오늘의 지면에서는 모아온 기술 소식을 누구나 읽을 수 있습니다. 뉴스레터는 그 주에 모은 자료를 연결해 확인된 사실과 앞으로 검증할 전망을 구분합니다.

개인에게는 깊이 읽는 한 편

뉴스와 논문을 살펴볼 시간을 줄이고, 연구 질문과 다음 실험을 찾도록 돕습니다. 뉴스레터는 로그인 후 읽을 수 있으며 현재 무료 열람 기간입니다.

팀에게는 함께 결정하는 자료

회의용 요약, 연구 우선순위표, 실험·평가 양식으로 팀의 검토를 이어갈 수 있습니다. 본문과 재게재가 허락된 그림은 출처를 밝혀 활용할 수 있습니다.

향후 개인·기업 구독을 준비하고 있습니다. 현재 결제나 자동 청구는 없으며 가격과 도입 일정은 정해지지 않았습니다.
