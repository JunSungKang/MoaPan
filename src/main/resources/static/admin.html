수집 주소·권리

신규 주소는 비활성·권리 미검토 상태로 저장합니다. 권리 검토 후 수정 저장→기술 점검→수정 화면에서 사용 체크→사이트 활성화 순서로 진행하세요.

제목·설명에서 주제를 찾습니다. 시작일을 지정하면 발행일이 없는 자료는 제외합니다. 논문만 수집하려면 논문 전용 API 주소를 등록하세요.

API·인증 고급 연결 설정

RSS·Atom은 보통 비워둡니다. 공식 API의 항목 경로를 연결하거나 운영 환경에 등록된 인증 정보 이름을 지정할 때만 사용합니다. 비밀번호나 인증키 값을 입력하지 마세요.

수집 작업 조회

최근 50개 작업에서 출처·요청 시각·상태를 보고 선택하세요. 지금 수집을 누르면 해당 작업이 자동으로 선택됩니다.









기사·요약 검토


원문 근거와 비교해 요약·태그·공개 여부를 검토하세요.


발행일이 아닌 담고담고에 수집된 날짜를 한국 시간으로 조회합니다. 조건에 맞는 기사를 최대 100개 표시합니다.

AI가 기사의 주제를 고르는 기준
  1. 주제 목록에서 기사에 사용할 주제 이름을 먼저 만드세요.
  2. 아래에서 자동 분류에 사용할 주제를 최대 8개 선택하세요.
  3. 각 주제에 포함할 내용과 제외할 내용을 적고 저장하세요.
저장하면 기존 기사를 순차 재분류합니다. 관리자가 잠근 기사 주제는 바뀌지 않습니다.

    대표 관심사
    로그인하지 않았거나 개인 관심사를 설정하지 않은 이용자에게 적용할 공통 주제입니다. 최소 1개, 최대 30개를 선택해 주세요.
    

    

    

    

    


    광고 관리
    우측 상단 광고를 관리합니다. CPC는 클릭당 과금 방식입니다. 클릭 집계와 정산은 계약한 광고 서비스에서 확인하며 담고담고는 클릭을 추적하지 않습니다.
    

    이미지는 서버에 준비된 PNG·JPEG·WebP·GIF 파일만 사용할 수 있습니다. 이미지가 없으면 광고 문구를 표시합니다.
    두 값은 담고담고의 내부 번호가 아니라 Google이 발급한 광고 연결 정보입니다. 애드센스에서 복사해 붙여 넣으세요.
    애드센스는 연결 준비 상태입니다. 승인된 사이트와 광고 단위, 동의 관리 설정을 확인한 뒤 송출 연결이 필요합니다. 정보 저장만으로 Google 광고가 요청되지는 않습니다.
