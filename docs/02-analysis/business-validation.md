# 구독 뉴스레터 사업화 기반·실무 검증 계획서

> 문서번호: MP-DOC-028 · 기준: 저장소 현재 리비전 · 상태: 유지관리 · 작성: 개발 담당 · 검토: 독립 리뷰 담당

## 승인과 범위
사용자가 개인 구독(1), 기업 구독(2), 출처를 밝히는 자유 재게재(5)를 조합했다. 가격·실결제·자동 청구는 추후 사용자 결정이다. 앞선 공개 뉴스 수정 지시는 계획 변경이었는데 구현을 먼저 수행했다. 이번에는 나머지 계획의 구현을 명시 승인했다. 이후 계획 요청만으로 구현하지 않는다. develop/main 병합·실제 참가자 연락·사업 개시 승인을 포함하지 않는다.

| 원래 계획 | 이번 반영 | 완료 판별 |
|---|---|---|
| 주간 근거·연구 기준 | 수집 기사ID·검토 기준시각·사실/전망/기간/실험/성공/중단 조건, 편집·권리 확인, 발간 전 점검 | 서버 gate, 주간/철회/미수집 링크/동시수정 검사 |
| 출처 포함 재게재 | 본문 복사, 그림 포함 HTML, 원문 링크·호수·개정판·제공 유형 | 무료/유료 문구 구분, XSS·권한·귀속 검사 |
| 공개 유입 | 오늘의 수집 뉴스·검색만 비회원 공개; 소개에 개인·팀 활용 설명 | 뉴스레터와 다른 기능의 인증 유지; 공개 뉴스레터 샘플은 최신 변경으로 제외 |
| 기업 가치 검증 | 근거 연결 회의 요약·연구 우선순위/의사결정표·실험/평가 양식 | 실제 발간본에서 양식 생성, 원문/개인정보 미포함 |
| 페르소나별 평가 | 모집·동의·교차 제시·고정 과제/판정·익명 집계 도구 | 실제 참가자 없이 결과/성공확률을 채우지 않음 |
| 향후 구독 경계 | USER/ADMIN과 분리한 혜택·유효기간 정책 및 provider port | 모든 회원 무료 preview, paid 설정은 시작 실패, 실제 청구 없음 |

## 수익이 생기는 구조와 준비 단계
개인은 지속되는 주간 해설·근거 검토·정정판·연구 질문에 가치를 느낄 때 구독한다. 기업은 동일 핵심 콘텐츠를 업무 자료로 검토·이용하는 편의에 가치를 느낄 때 구독한다. 기업에만 재게재 권한을 판매하지 않으며 개인도 출처를 밝히면 활용할 수 있다. 재게재의 원문 링크는 브랜드 유입 통로다. 추적 픽셀·회원 행동 분석을 추가하지 않는다. 실제 구매·갱신·매출은 결제가 없으므로 아직 확인할 수 없다. 조직 구성원/자료함 SaaS는 실제 기업 검증 후 별도 계획·승인 대상으로 남긴다.

## 근거·발간 규칙
신규 호는 Asia/Seoul 해당 주 월요일00:00~검토 cutoff에 실제 collected_at이 속하는 자료를 사용한다. 각 전망은 선택한 근거와 연결한다. 원문 링크 블록도 선택한 수집 자료 URL이어야 한다. 원문/초록을 따로 저장하지 않는다. 의미 정확성·권리 보유 자체를 코드가 보증하지 않으므로 편집자가 사실·가설·제안 수치와 재게재 권한을 확인한다. 자료의 출처 공개 권리가 철회되면 연결 발간본도 목록/본문/내보내기에서 제외한다.
정정판은 최초 호수·최초 발간시각·원래 근거 주간을 유지하고 현재 발간시각/개정 수/개정 내용을 갱신한다. 따라서 지난 호 정정에 현재 주 자료를 끼워 넣지 않는다. 기존 V13 원고/발간본은 보존하며 구조화 전 발간본에는 재게재 도구를 활성화하지 않는다.

## 재게재 정책
모아판이 이용 허락을 부여할 수 있는 자체 원고·그림만 허락한다. 채널·횟수·추가 라이선스 요금을 제한하지 않는다. 출처·제공 문구·원문 링크를 포함한다. 실제 무료 열람판에는 무료 문구를 표시한다. 실제 유료 구독판에 사용할 문구는 “이 콘텐츠는 모아판(MoA-PaN)의 유료 구독 뉴스레터를 통해 제공되었습니다.”다. 현재 유료판을 발간하거나 결제된 것처럼 표시하지 않는다. 수집한 기사/논문 전문과 제3자 그림 권리는 제공하지 않는다. [저작권법 제46조 공식 경로](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0046&lsiSeq=283335&urlMode=lsScJoRltInfoR)는 확인했으나 브라우저 추출에 조문 본문이 노출되지 않았다. 사업 전 권리 및 법률 검토 완료로 주장하지 않는다.

## 동일 과제와 사전 기준
1. 목적·자발성·익명 집계만 보관한다는 안내 후 동의를 받는다. 초대/완료/중도 이탈 수를 구분한다. 개인 응답/연락처를 모아판에 저장하지 않는다.
2. 같은 주의 자료를 기사 목록 A와 뉴스레터+양식 B로 제시한다. 절반은 A→B, 절반은 B→A, 자료 난이도를 맞추고 사전 기준을 고정한다.
3. 연구 질문·근거 두 항목·다음 실험·중단 조건을 찾는다. 독립 평가표의 4항목을 모두 충족하고 A보다 완료 시간이20% 이상 단축된 경우를 초기 ‘향상’ 기준으로 제안한다. 이20%는 제품 성과가 아닌 연구 설계 제안이며 모집 전에 확정한다.
4. 다음 호를 실제 선택한 수, 출처를 보존해 재게재물을 완성한 수, 기업 내부 시범 논의가 진행된 수를 별도로 집계한다. ‘좋아요’ 답변이나 구독 의향을 실제 구매로 세지 않는다. 가격 미정 상태의 결과는 유료 구매/갱신 증거가 아니다.
5. 집단별 완료 분모와 향상 분자를 보고한다. 모집 목표 미달이면 미충족/추가 조사, 완료 표본 내 향상 비율이 각 집단60% 초과면 ‘표본 내 실무 기준 충족’만 표시한다. 이는 시장 전체 성공 가능성60% 초과라는 뜻이 아니다. 회사와 사람을 하나의 성공률로 합치지 않는다.

관리자 [평가 준비·집계](/research-evaluation.html)는 명시 입력한 익명 집계만 메모리에서 계산하고 JSON 내보내기/가져오기를 지원한다. 초기값은0이며 화면 판정은 ‘미실행’이다. 개인 응답, 조직명, 식별자, 열람/클릭/검색 이력을 받지 않는다. import는 정확한 스키마/정수/분자≤분모/용량을 검사하며 오류 시 기존 집계를 유지한다. 실제 조사·고객 모집은 이번 코드 작업에서 수행하지 않았다.

## 기준 미달일 때 중복하지 않을 후속안
- 개인 과제 성과가 낮으면 주간 장문을 늘리는 대신 한 연구 질문의 상충 근거를 비교하는 실험 설계팩으로 전환하는 안을 제안한다.
- 기업의 시범 논의가 없으면 조직 SaaS를 만들지 않고 기존 회의 절차에 들어가는 특정 직무 검토 패키지/도입 자문 범위를 재설계한다.
- 재게재 과제에서 귀속이 누락되면 이용권을 좁히는 대신 완성된 귀속 텍스트와 출처 페이지의 이해 가능성을 다시 시험한다.
- 운영비가 높으면 분야를 무조건 넓히지 않고 검증 가능한 한 연구 의제와 고정 발간 공정으로 좁히는 안을 제안한다.
실측이 없으므로 현재 실패나 성공 가능성을60%로 단정하지 않는다. 후속 대안의 실행은 평가와 새 계획 제시 후 별도 구현 승인을 받는다.

## 근거와 해석 범위
- [GOV.UK 사용자 연구 계획](https://www.gov.uk/service-manual/user-research/plan-user-research-for-your-service): 사용자 집단과 연구 질문을 먼저 정한다. 이 프로젝트의 모집 수·20% 기준을 정부 권고 수치로 표시하지 않는다.
- [AAPOR 조사 모범사례](https://aapor.org/standards-and-ethics/best-practices/): 할당/자발 모집과 확률 표본을 구분하고 표본 구성·문항·모집방법을 투명하게 보고한다.
- [NIST 비율 구간](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm): Wilson식은 확률 표본 조건 검토 없이 시장 확률을 만드는 도구가 아니다. 이번 할당 모집 도구는 모집단 신뢰구간을 출력하지 않는다.
공식 페이지를 이번 작업 중 실제 조회했다. 상업 성공·법률 적합성·고객 효과를 검증했다고 주장하지 않는다.
