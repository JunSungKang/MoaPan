# 요구사항

> 문서번호: MP-DOC-004 · 기준: 저장소 현재 리비전 · 상태: 유지관리 · 작성: 개발 담당 · 검토: 독립 리뷰 담당

제품 목표: 여러 출처의 뉴스를 관심사에 맞게 모아 종이신문처럼 읽는 개인화 뉴스 플랫폼. 기술적 완성과 사업 개시는 별도다.

|---|---|---|---|
|REQ-01|실제 데이터|허용된 실제 출처의 수집·수정·갱신|AC-16~19|
|REQ-02|수집 사이트 관리|DB 기반 사이트·주소 관리와 재배포 없는 표준 주소 추가|AC-11~15|
|REQ-03|최소 회원가입|아이디·비밀번호만 수집하고 안전한 세션 운영|AC-06~08|

|REQ-05|계정별 개인화|현재 브라우저에서 계정별 설정 분리·추천|AC-20|

공통 제약: 서버 회원 개인 관심사·추적·원문 전문 공개·프로필·소셜 로그인·유료 AI 기본 사용·금지 스택 제외. CI/CD는 최신 지시로 범위에서 제외. 전체 후보의 개인정보 비전송과 응답 제한을 함께 충족해야 한다.

최신 사용자 변경: 오늘의 지면에 수집한 뉴스와 기사 검색은 로그인 없이 이용한다. 뉴스레터·개인 관심사·계정·관리는 로그인/권한이 필요하다. 가입·소개·약관은 공개하며 뉴스 지면 하나를 제공한다. 개인 관심사 미설정/비활성 시 관리자 공통 대표값을 사용한다. 대표값은 운영 설정으로 서버 저장하고 회원 개인 설정은 저장하지 않는다. 검색은 팝업에서 설정 후 서버에서 최신순 최대140개를 7개씩 조회한다. 약관 표시에는 날짜 대신 판 번호를 쓰며 현재는 최초 제1판이며 이전 이력은 없다.

REQ-13(사용자 추가): 관리자가 재배포 없이 광고 문구·링크·표시상태와 애드센스 연결 정보를 관리한다. 회원의 개인 관심사·행위를 광고 처리에 사용하지 않는다. 애드센스 실송출은 미포함(등록·연결 준비만 명시 승인). FS-27과 광고 관리 통합/E2E로 검증한다.

REQ-14(승인 추가): 관리자가 뉴스·논문을 근거로 미래 트렌드 전망을 산문/설득형/잡지형 글과 그림으로 작성·발간한다. 회원은 발간본만 읽고 초안은 관리자만 접근한다. 기존 뉴스 지면과 목록·본문·편집기를 구분하며 이메일 주소 수집/메일 발송은 포함하지 않는다.

REQ-15(승인 추가): 관리자가 주간 수집 근거, 확인 사실과 조건부 전망, 연구 기간·실험·성공/중단 기준을 연결하고 발간 전에 서버 검증한다. 기존 원고/호수를 보존하고 정정은 원래 근거 주간을 유지한다.
REQ-16(승인 추가): 재게재 권한 검토를 통과한 자체 뉴스레터 본문/그림은 출처·제공 유형·원문 링크와 함께 복사/파일로 활용한다. 채널·횟수·추가 이용료 제한 없음. 수집 원문/제3자 권리 제외, 실제 무료/유료 문구 구분.
REQ-17(승인 추가): 회원에게 근거 연결 회의 요약·연구 우선순위·실험/평가 양식을 제공한다. 제품 개선 전후의 재평가는 별도 분석 문서로 수행하며 서비스에 평가 화면·집계 기능을 제공하지 않는다. 실제 조사·매출·성공 확률을 생성하지 않는다.
REQ-18(승인 추가): USER/ADMIN 운영 권한과 향후 구독 혜택 port를 분리한다. 현재 무료preview이며 가격/실결제/자동청구·조직 SaaS/고객 연락은 추후 승인 사항이다. 전체 사업화 분석·평가 기준은 [MP-DOC-028](business-validation.md).
