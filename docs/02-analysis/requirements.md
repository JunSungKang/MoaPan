# 요구사항

> 문서번호: MP-DOC-004 · 기준: 저장소 현재 리비전 · 상태: 유지관리 · 작성: 개발 담당 · 검토: 독립 리뷰 담당

제품 목표: 여러 출처의 뉴스를 관심사에 맞게 모아 종이신문처럼 읽는 개인화 뉴스 플랫폼. 기술적 완성과 사업 개시는 별도다.

|ID|목적|요구·제약|인수 기준|
|---|---|---|---|
|REQ-01|실제 데이터|허용된 실제 출처의 수집·수정·갱신|AC-16~19|
|REQ-02|수집 사이트 관리|DB 기반 사이트·주소 관리와 재배포 없는 표준 주소 추가|AC-11~15|
|REQ-03|최소 회원가입|아이디·비밀번호만 수집하고 안전한 세션 운영|AC-06~08|
|REQ-04|개인화 비전송|관심 문장·설정·행위 이력은 비전송. 승인된 기사 검색 조건만 서버 일시 처리하며 저장·로그·외부 전송 금지|AC-21|
|REQ-05|계정별 개인화|현재 브라우저에서 계정별 설정 분리·추천|AC-20|
|REQ-06|요약·태그·원문|이용조건에 맞는 근거 기반 요약·정규화 태그·원문 연결|AC-16,19|
|REQ-07|정적 신문|HTML/CSS/Vanilla ES Modules와 REST API로 신문 화면 제공|AC-05,22|
|REQ-08|API 보호|인증·권한·필드·기간·항목·호출량을 제한|AC-07~10|

공통 제약: 서버 회원 개인 관심사·추적·원문 전문 공개·프로필·소셜 로그인·유료 AI 기본 사용·금지 스택 제외. CI/CD는 최신 지시로 범위에서 제외. 전체 후보의 개인정보 비전송과 응답 제한을 함께 충족해야 한다.

최신 사용자 변경: 뉴스 지면과 뉴스 API는 로그인해야 이용한다. 가입·소개·약관은 공개하며 회원에게 관심지면 하나를 제공한다. 개인 관심사 미설정/비활성 시 관리자 공통 대표값을 사용한다. 대표값은 운영 설정으로 서버 저장하고 회원 개인 설정은 저장하지 않는다. 검색은 팝업에서 설정 후 서버에서 최신순 최대140개를 7개씩 조회한다. 약관 표시에는 날짜 대신 판 번호를 쓰며 현재는 최초 제1판이며 이전 이력은 없다.
