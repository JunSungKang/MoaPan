## 독립 리뷰의 추가 수정
첫 독립리뷰는 P2 두건으로 CHANGES_REQUESTED였다. guestMenu의범위밖a참조를제거하고뉴스레터가용성상실처리를공통함수로분리했다. 목록/본문뿐아니라재게재/worksheet 요청의404도공통이벤트로메뉴/기존본문을정리하고실제404문서로이동한다. 로그인204/401 초기화·이미읽는중인로그인상실·복사/재게재/회의/우선순위/실험양식5버튼의404를추가브라우저회귀로검증한다. 서버권한검사와404/503의미는완화하지않는다.
