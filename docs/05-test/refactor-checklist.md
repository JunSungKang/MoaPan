## 판정 원칙

서로 다른 CSS 파일 자체는 중복 결함이 아니다. 공통 규칙·도메인 전용 규칙·반응형/인쇄 의도는 구분한다. 같은 선택자/미디어 문맥에서 실제 덮인 선언만 제거하고, 전후 computed style과 기능 시험으로 확인한다. 이름 검색만으로 framework·직렬화·동적 import를 삭제하지 않는다. 특화 JSON parser, URL/SSRF/외부링크 정책은 각 보안 경계를 유지한다. 제거 소스는 별도 백업/stash를 만들지 않는다.


추가 확인: RF04에서 구형 local-smoke의 README 실행 권고와 현재 SOURCES의 재실행 금지가 모순됨을 확인해 실행기를 폐기하고 현행 명령을 정정했다. RF05의 AST 검사가 ArticleFingerprint의 추가 생성 경로를 탐지했다. 기존 구현의 합성 해시2개를 실측한 뒤 정적 매퍼로 변경했으며 동일성을 회귀 검증한다. 회원가입 페이지의 언어 선택 fallback은 실제 사용 중임을 확인해 유지했고, 어느 지면에서도 도달하지 않는 searchButton fallback 분기만 제거했다.

## 처리 결과와 재발 방지

- 공통 CSS는 newspaper.css 한 곳이 소유하고 인증·관리·발간 전용 규칙은 해당 페이지에서만 적재한다. 서로 다른 파일을 두 번 받는 것과 같은 파일을 중복 요청하는 것은 구분한다. 상쇄 선언52개와 죽은 masthead 선택자3개를 제거했다. CSS 전체를 읽기 쉬운 규칙 단위로 정리했다.
- Java7클래스의 요청·기사·계량별 기본 매퍼 생성9경로를 클래스 소유 자원으로 바꿨다. 보안 한도가 다른 파서는 합치지 않았다. 별칭 정규식은 최대256개만 재사용한다. 회원·기사 본문을 캐시하지 않는다.
- 지면의 도달 불가능한 언어/검색 분기와 구형 local-smoke 실행기를 제거했다. 구형 실행기는 현재 수집 정책과 달리 NASA/NOAA를 재활성화하므로 README·배포·출처의 모순된 실행 안내도 정정했다. 실제 사용 중인 가입 언어 fallback은 보존했다. 소스 백업·stash는 만들지 않았다.
- HTML11개/ES Module38개·Java67파일732선언·scripts85파일을 진입점/심볼/동적 DOM/문서 지침과 교차 조사했다. 프레임워크·보안 hook과 재현 도구는 실제 용도가 있으므로 보존했다. 정적 분석만으로 모든 동적 경로를 증명했다고 주장하지 않는다.
- sourceCheck에 CSS8개 회귀 시험과 기본 read-only 검사를 연결했다. 공백 차이·media·shorthand·important·따옴표·파싱 실패를 시험한다. Java AST 검사는 메서드/필드 lambda의 매퍼 재생성을 탐지하며, 실제 추가 누락 ArticleFingerprint를 찾아 수정했다.
