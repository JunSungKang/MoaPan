## ENV-001 실행 설정의 이미지 포함
DB 초기화 스크립트와 Caddyfile은 비밀값 없는 고정 배포 설정이므로 Dockerfile COPY로 포함한다. Compose 실행 시 host bind mount 두 개를 제거하고 DB/Caddy named volume은 그대로 유지한다. 설정 변경은 해당 이미지 재빌드·재스캔 후 반영한다. 파일 공유 정체의 노출 경로를 제거하는 변경이며 Docker 자체 결함 해결을 대신 증명하지 않는다.

- 사용자 완료 기준 변경: 별도 배포 검증 제외, 로컬 실행+외부 접속. 공인 IPv4 직접 연결에 Caddy/Let’s Encrypt shortlived IP 인증서를 사용하고 SNI 없는 IP 접속은 default_sni로 같은 인증서를 선택한다. 참고: https://letsencrypt.org/2026/01/15/6day-and-ip-general-availability 및 https://caddyserver.com/docs/caddyfile/options#default-sni . 인증서 검증 비활성화·공개 터널·도메인 구매 없음.

## 기기 간 관심사 이전 (2026-10-28)
서버 비전송 경계를 유지하며 암호화 파일의 수동 이전을 채택했다. IndexedDB는 브라우저/출처별 저장이며 계정 로그인만으로 다른 PC와 동기화되지 않는다. 자동 동기화는 서버 등 공유 저장소 또는 동시에 연결된 기기를 요구한다. WebRTC도 신호 교환 및 NAT 환경에 따른 STUN/TURN이 필요해 V1에서 추가하지 않았다.
네이티브 WebCrypto PBKDF2-HMAC-SHA256 600,000회, 무작위16바이트 salt, AES-256-GCM, 매번 무작위12바이트 IV 및 형식 AAD. 파일 전용15~128자 비밀번호는 저장/전송하지 않는다. 로그인 비밀번호 정책은 변경하지 않는다. 브라우저 메모리의 완전 삭제나 악성 확장/XSS 방어를 암호화만으로 보장하지 않는다. 계정 UUID는 암호화 내부에만 포함, 다른 계정 적용을 UI에서 거부한다. 파일 비밀번호 보유자는 평문을 볼 수 있으므로 계정 비교를 암호학적 접근 통제로 주장하지 않는다.
최대128KiB, 필드 whitelist/설정개수500/가중치1~5/키검사/중복배열검사. 적용 전 명시적 확인·취소, 실패 시 기존값 보존. 현재 사전에 없는 유효한 설정 ID도 보존하고 병합 매핑 적용. 내보낸 파일은 서버/탈퇴/브라우저 초기화로 회수되지 않는다. 수동 이전 이후 각 기기는 독립적이며 최신 파일을 다시 옮겨야 한다.

## 카드 항목과 연구 요약
사용자 지정 여섯 항목만 카드에 남긴다. 언어·자동 처리 방식·추천 이유·태그 선호 조절 버튼은 카드에서 제거한다. 번역 전환 초안은 미연결 상태로 보존한다. 원문에 존재하는 방법/평가/한계/취약점 영향·대응 문장을 사전 기반으로 우선 추출하며 근거가 없으면 요약 부족으로 표시한다. 이는 새로운 연구 의의를 추론하거나 실험을 재현하는 분석이 아니다. 영어 자료는 현재 영어로 유지한다. 작성자는 출처가 제공한 이름만 사용하고 출판 기관·취약점 제보자를 임의로 저자로 간주하지 않는다.

현재 arXiv API 제목·저자·초록은 공식 API 이용조건의 CC0 메타데이터 범위이다(https://info.arxiv.org/help/api/tou.html, https://creativecommons.org/publicdomain/zero/1.0/ 확인). 사용자 요청에 따라 카드에 별도 인용문 라벨/논문식 참고문헌 블록은 추가하지 않는다. 작성자·출처·제목의 원문 링크는 유지한다. PDF 본문 및 다른 출처의 별도 라이선스에 이 결론을 일반화하지 않는다.
피드 최신 목록에서 빠진 기존 기사는 보관된 허용 요약 문장만으로 research-v2-stored 재선정한다. 외부 전문을 새로 가져오지 않으며 수동 잠금은 건너뛴다. 추후 재수집되면 전체 허용 설명 기준 research-v2로 갱신된다.

## 서버 검색 승인 반영
사용자가 검색어 일시 전송·미저장 방식을 승인했다. 원래 로컬 검색 제한을 이 범위에서 변경한다. 42개 지면 밖 저장자료를 찾기 위해 POST 본문으로 검색 조건을 전송하며 URL·쿼리 로그·검색이력 테이블은 사용하지 않는다. 검색은 개인화 정렬과 분리해 최신순7개/최대20페이지. 모든 결과를 처음부터 자동 다운로드하지 않는다. 검색어 기반 cache/key/counter도 만들지 않는다. 기존 DB10초 statement timeout과 전역/회원 quota를 적용한다. 번역 엔진이 없는 기사에는 번역한 것처럼 표시하지 않는다.

사용자 요청으로 원문 미보관을 명시적 불변 조건으로 확정했다. 조사 결과 기존 운영 경로가 이미 이를 충족하므로 제품 코드·DB 스키마·실행 이미지를 불필요하게 변경하지 않는다. 원문 전용 표식을 포함한 합성 입력을 신규/변경 수집해 본문 미저장을 검증하는 PostgreSQL 회귀 테스트를 추가했다. 저장 요약은 유지하며 입력 전문과 혼동하여 삭제하지 않는다.

### 경량 로컬 번역
사용자 승인에 따라 외부 유료API 없이 Index-Translate2B 공식Q8을 선택했다. 공식평가·실제8문장 비교·한계는 TRANSLATION_MODELS.md. 모델이 기사를 재요약하지 않고 저장 제목/요약만 번역한다. 개인화·검색과 분리된 worker, 입력 변경 무효화, 권리 재검사,수치/식별자 검증. Ollama 기본키 생성의 workspace밖 쓰기를 피하기 위해 workspace-contained llama.cpp를 사용한다.

- 2026-10-29: 사용자 확정에 따라 Index Translate 2B Q8_0 + glossary-v1 선택. 35개 양방향 기술 용어를 TSV로 분리하고 원문 일치 항목만 prompt에 포함한다. 모호한 readers 같은 일반 단어는 전역 치환하지 않는다. 번역은 저장 제목·요약에 한정하며 숫자/CVE 검증 실패는 원문 유지.


### Linux 운영 기준 자동 번역
사용자 승인: Linux CPU Docker 서비스, Index2B Q8 유지. Mac Metal/host.docker.internal 의존성을 제거한다. 모델 자체의 자기평가 대신 수치·단위·식별자·일부 부정/방향/핵심용어 규칙으로 보수적 공개 gate를 적용한다. 항목별 최대3회 이후 원문 유지로 자동 종결하며 인프라 실패는 별도 backoff 후 재개한다. GPU와 원격 서버 성능은 실제 장비 확보 후 검증한다. CI/CD는 추가하지 않는다.


### 중간 정리와 Kubernetes 요청 반영
필수문서/Gradle표준 경로는 유지하고 운영 도구를 scripts 하위 기능별로 분리한다. 과거 비교실험은 삭제 대신 experiments에 격리하여 재현성을 보존한다. 사용자 최신 요청으로 Helm 배치를 추가하지만 CI/CD 제외는 유지한다. 모델은 Git/이미지에 넣지 않고 HF 고정revision과SHA256으로 실행 시 준비한다. 외부registry/클러스터가 없으므로 임의 자원 생성 없이 chart 검증 범위만 보고한다.

## Qwen3.5-4B 분류 전용 서비스
사용자 선정에 따라 Q4_K_M으로 고정했다. 번역 모델과 목적/비밀값/네트워크/모델 볼륨을 분리하고 Java worker의 DB 큐로 비동기 처리한다. 주제 정의는 운영 DB와 관리자 편집 화면에서 관리하며 LLM 자유 태그 생성은 허용하지 않는다. 기존 개인 설정과 태그 ID를 임의 병합하지 않는다. 초기5개 주제는 변경 가능한 기본값이다. 30회 모델 비교를 재실행하지 않고 fixture 회귀와 소수 실제 연동만 검증한다. 자세한 경계는 CLASSIFICATION.md.

분류 리뷰 보강: 기사 전체 태그 잠금도 내용 변경 trigger에서 보존하며 V11로 적용한다(V10은 로컬 적용 완료하여 checksum을 바꾸지 않음). 수동 태그를 우선하고 총6개까지 자동 태그를 추가한다. 요약 허용을 철회한 출처는 보수적으로 저장 요약 기반 분류 대상에서 제외한다.

## 선택적 자동 로그인과 회원 지면
사용자 요청으로 비회원 뉴스 제공과 remember-me 제외를 변경한다. 이미 검증된 Spring Session JDBC를 사용하고 DefaultCookieSerializer에서 서버 remember-until 속성에 한해서 SESSION Max-Age를 설정한다. 별도 비밀번호/브라우저localStorage토큰/장치지문/장기IP기록을 추가하지 않는다. 최대30일 절대기간(연장없음)이며 세션DB와 쿠키가 함께 필요하다. 로그아웃은 해당세션만, 비밀번호변경/탈퇴는 모든세션 폐기. 새 영속 token표나 마이그레이션 없이 역할별 공통JAR/Compose/Helm 사용.

아이디 저장: 로그인 화면의 별도 opt-in localStorage 키에는 아이디만 저장한다. 자동 로그인 선택은 아이디 저장을 강제 체크/비활성화한다. 자동 로그인 해제 후 별도 저장 해제 가능하며 즉시 삭제한다. 로그아웃은 인증만 해제하며 선택한 아이디 저장은 유지한다. 저장소 사용 불가 시 로그인 자체는 계속 가능하다.

보안재검토: 프록시와별개로앱이CSRF/JSON전에실제16KB본문을강제한다. 스캐너보고서는다운로드시각뿐아니라DB발행시각/NextUpdate/보고서생성도검증한다. JDK공급자버전만으로공식4루트조치를추정하지않고명시적재현가능cacerts변경과실제TLS검사를병행한다.

최신 사용자 광고 요청으로 V1 광고 제외 범위를 직접 링크 배너와 애드센스 연결 정보 관리에 한해 변경했다. CPC는 과금 방식이며 클릭 정산은 외부 광고 계약의 책임이다. 사용자가 애드센스 승인/ID가 아직 없다고 답하고 등록·연결 준비만 요청했으므로 ADSENSE는 저장만 가능하고 활성화는 차단한다. 실제 Google SDK·CSP 완화·CMP를 임의 구현하거나 광고 송출 완료로 표시하지 않는다. 도입 전 승인된 사이트/광고 단위와 공식 strict CSP·인증 CMP 요구사항을 확인하고 별도 연결 검증한다.
