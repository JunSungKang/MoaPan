# 개인정보 경계

> 문서번호: MP-DOC-021 · 기준: 저장소 현재 리비전 · 상태: 유지관리 · 작성: 개발 담당 · 검토: 독립 리뷰 담당

이름·전화번호는 받지 않는다. 수신 이메일은 가입 인증·비밀번호 복구·결제/구독 안내에만 사용하고 마케팅·광고·기타 목적 사용을 금지한다. 관심사 설정은 현재 브라우저 안에 저장한다.

서버는 아이디·Argon2id 해시·계정 UUID·권한·활성 상태·세션과 목적별 제한 카운터를 처리한다. 네트워크 연결에 IP의 일시 처리가 필요하지만 프로필·IP/UA 접근 이력·기사 클릭·체류시간을 저장하는 기능은 없다. 요청 본문·쿠키·비밀번호·관심사·검색을 로그에 기록하지 않는다.

IndexedDB는 UUID별 namespace로 설정·태그 가중치·제외만 저장한다. 문장은 로컬 매칭과 확인 후 폐기한다. 비밀번호·토큰·기사 아카이브는 저장하지 않는다. 기기 간 자동 동기화와 전화 복구는 없다. 이메일 복구는 계정에 사전 인증한 주소만 사용한다. 브라우저 데이터 삭제 시 설정도 사라진다. 같은 브라우저 프로필에 접근하는 다른 사람에 대한 암호학적 비밀성을 보장하지 않는다. 로그아웃은 기사 메모리와 화면을 비우며, 탈퇴는 현재 계정 설정도 삭제한다. 오프라인 다른 기기의 즉시 삭제는 보장하지 않는다.

외부 폰트·분석·광고 SDK·추적 픽셀·원문 클릭 중계는 없다. 원문 직접 링크 이동 후의 데이터 처리는 원문 사이트 정책에 따른다. 호스팅 사업자 로그는 배포 전에 별도로 확인해야 한다.

신규 가입 약관 동의 버전·서버 시각을 users에 최소 저장한다. 별도 개인정보 마케팅 동의를 요구하지 않는다. 탈퇴 시 동의 기록도 삭제하며 기존 회원의 동의를 소급 생성하지 않는다. 운영자 표시명·연락처는 미제공 상태를 정책 페이지에 명시했다.

## 사용자가 직접 옮기는 관심사 파일
파일과 파일 비밀번호는 WebCrypto로 브라우저 안에서만 처리한다. UUID 및 관심/제외 설정이 암호화된 파일에 포함된다. 네트워크 요청이나 서버 저장은 추가하지 않았다. 내보낸 복사본은 탈퇴/로컬 초기화로 삭제되지 않으므로 사용자가 직접 관리한다. 다른 기기로 파일을 전달하는 서비스의 처리는 별도다. 기기별 변경은 자동 전파되지 않는다. 비밀번호 분실 시 파일 복구 기능 없음.

대표 관심사는 관리자 공통 운영 설정이며 회원 프로필이 아니다. 대표값 변경 감사는 기존 admin_actions에 작업 종류/관리자/시각만 기록한다. 비회원 기사 조회 한도는 전역 공유 counter이며 IP/UA 이력과 기기식별자 없이 처리한다. 검색 조건은 실행/결과 페이지 이동 시 POST 본문으로 같은 origin 서버에 전송한다. 검색 처리 후 DB·로그·회원별 이력·캐시에 남기지 않는다. URL에는 포함하지 않고 입력 중에는 전송하지 않는다. 검색 조건은 브라우저 메모리에만 보관하며 관심사 설정은 이 요청에 포함하지 않는다.

정상 세션 만료·일반401은 화면 인증 상태만 정리하며 IndexedDB 관심사를 삭제하지 않는다. 현재 브라우저의 명시적 탈퇴 성공 또는 개인화 삭제 요청에서만 삭제한다. 다른 브라우저의 계정 삭제와 세션 만료를401만으로 구별할 수 없어 원격 즉시 삭제를 보장하지 않는다.

선택적 자동 로그인은 서버 세션의 만료시각과 HttpOnly SESSION 쿠키로 처리하며 최대30일이다. 현재 브라우저 기준이고 다른 브라우저에 자동 공유하지 않는다. 해당 브라우저 로그아웃 시 서버세션과 쿠키를 폐기한다. 비밀번호변경/탈퇴는 계정의 전체세션을 폐기한다.

관리자 배너는 일반 HTTPS 직접 링크이며 개인화 설정을 광고에 사용하거나 클릭을 기록하지 않는다. 애드센스 식별자 저장은 외부 광고 SDK 활성화가 아니다. 실제 Google 연동 시 동의·외부 처리 정책을 다시 정리해야 한다.

뉴스레터 연구 메모는 편집부가 작성한 공통 콘텐츠이며 회원 관심사가 아니다. 제품 평가 화면·집계·설문·참가자 정보 처리 기능은 없다. 구독 혜택은 preview port이며 현재 결제·청구·기업 프로필 DB는 없다.

승인된 필수 이메일: V25 주소 암호문·HMAC조회키·인증/안내 확인 시각, 5분 인증 도전과 최대하루 암호화 outbox를 처리한다. 공개 계정 응답과 관리자 목록에 주소를 추가하지 않고 본인 전용 API에서만 복호화한다. 주소·번호·내용을 로그/AI/광고/분석 도구에 보내지 않는다. 서버 발송 완료 시 outbox본문을 지우며 SMTP 전달/수신 메일함은 별도 처리 경계다. 기존 미등록 계정은 삭제하지 않고 본인 등록을 안내한다. 결제 기능은 미구현이다.

SMTP 중계의 큐·테스트 수신함·계정 맵은 용량이 제한된 메모리 파일시스템만 사용하며, 인증번호와 수신 주소를 SMTP 영속 볼륨에 남기지 않는다. SMTP 큐는 최대5분이며 재시작 시 소실될 수 있다. 애플리케이션 PostgreSQL의 발송 대기 내용은 별도로 암호화해 재시도하지만, SMTP 수락 이후의 받은편지함 도착을 보장하지 않는다. 메일이 도착하지 않으면 새 인증번호를 요청해야 한다. 미래 결제 기능의 영수증 발송·재전송 보장은 그 기능을 구현할 때 별도 검증한다. 이메일 데이터 키를 분실하거나 기존 DB와 다른 키로 교체하면 복호화와 복구가 불가능하므로 기존 키를 별도로 안전하게 보관·이관한다.
