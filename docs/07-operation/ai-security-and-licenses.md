# AI 보안·윤리 및 오픈소스 관리서

문서번호 MP-DOC-029. 대상은 현재 고정된 Index-Translate-2B 번역기와 Qwen3.5-4B 기사 분류기다. 최초 20개 보안 항목은 수정하지 않으며 추가 승인 범위는 [A01~A06](../05-test/evidence/security-ai-oss-followup-20261031.json)으로 구분한다.

## 1. 데이터와 권한 경계

모델은 서버 내부에서 기사 제목·허용된 요약만 처리한다. 회원정보·관심 문장·관심 가중치·검색어를 모델에 보내지 않는다. 원문과 모델 응답 전문을 작업 payload·로그·캐시로 보관하지 않는다. 모델에 셸, SQL, 웹 탐색, 파일 조작, 외부 도구 실행 권한을 제공하지 않는다. 프롬프트에 비밀키를 넣지 않는다.

입력 기사는 비신뢰 자료다. 지시는 system 메시지, 기사 텍스트는 user 메시지의 JSON 필드로 구분한다. 이 구분만으로 프롬프트 주입이 완전히 차단되는 것은 아니다. 결과가 형식 검증을 통과해도 의미가 잘못될 수 있으므로 아래의 권한·검증·실패 처리 경계를 함께 적용한다.

## 2. 출력과 자원 제한

| 경계 | 실제 처리 |
|---|---|
| 공통 응답 | 완료된 단일 텍스트 응답만 허용. 중복 JSON 키·후행 문서·도구/함수 호출·거절 객체·잘린 응답 거부 |
| JSON 복잡도 | 중첩16, 문서32,768, 문자열24,000, 이름128, 숫자64, 토큰8,192 상한 |
| 번역 | 입력1,500자, 보호표식 확장4,000자, 응답32KiB, 출력1,200토큰, 제한된 재시도0~2 |
| 번역 검증 | 수치·식별자·용어·언어·부정·비교 방향의 결정적 검사. 실패하면 번역 완료로 저장하지 않음 |
| 분류 | 제목500/요약1,600 코드포인트, 요약 최대6개, 관리자 주제1~8개, 출력 최대6개·160토큰·8KiB |
| 분류 검증 | 현재 주제 slug만 허용. 추가 필드·중복·없는 주제 거부. 임의의 민감한 회원 프로필 추정 없음 |
| 요청 제한 | adapter 인스턴스당 동시1개. 기존 PostgreSQL 작업 lease와 모델 단일 slot 병행 |
| 시간·망 | 연결3초, 분류180초, 번역 기본300초(설정10~600초), 고정 내부 호스트/포트/경로, redirect 금지 |

인스턴스별 semaphore는 분산 전역 제한을 대신하지 않는다. 여러 worker를 배치할 때는 기존 DB lease와 모델 slot·CPU/메모리 제한을 함께 유지한다. 네트워크 오류나 잘못된 응답이 발생해도 semaphore를 반환하며 무제한 재시도하지 않는다. 일반 회원의 임의 프롬프트 입력 API는 없다.

## 3. 정확성·편향·사용자 안내

AI 분류는 객관적 진리나 연구의 질적 평가가 아니다. 번역 검사는 의미 정확성이나 편향 부재를 보증하지 않는다. 화면의 소개 안내에서 자동 처리 사실·오류 가능성·원문 확인과 관리자 수정 경로를 설명한다. 관리자 수동 잠금과 정책 변경 시 오래된 결과 차단을 유지한다. 실패 시 검증되지 않은 결과 대신 기존 원문 언어 표시·미분류 상태를 유지한다.

분류 대상은 기사 주제이며 회원의 정치·건강·성향을 추정하지 않는다. 현재 모델을 자동 의사결정이나 자율 뉴스레터 발간 권한으로 확대하지 않는다. 연구 결과와 편집부 전망의 구분은 별도 편집 절차의 책임이다. 실제 독자나 평가 점수를 가공해 성능 증거로 쓰지 않는다.

## 4. 라이선스 및 공개 범위

[고지·소스 제공 의무](../../THIRD_PARTY_NOTICES.md)와 [실제 Java 목록](../../licenses/java-inventory.json)을 기준으로 관리한다. 현재 runtime100개 JAR의 선언과 실제 고지, 모델2개·실행기의 고정 버전을 조사했다. `licenseCheck`는 실제 의존성 SHA와 보존 고지 SHA가 달라지면 실패한다. 새 버전의 라이선스까지 자동 승인하지 않는다.

현재 웹서비스 사용만으로 독립된 MOAPAN 전체 소스를 공개해야 하는 의무는 확인되지 않았다. 모델의 Apache-2.0 표시가 학습자료·출력·상표 권리까지 보증하지는 않는다. EPL 라이브러리의 고지·공식 source JAR를 앱 이미지에 보존하며 JDK/OS의 GPL 대응 소스는 외부 이미지 배포 전에 별도 확인한다. 실제 의무 대상의 소스는 수령자가 받을 수 있게 제공해야 한다. 프로젝트 자체 라이선스는 소유자가 결정하며 이번 패치가 이를 대신하지 않는다.

## 5. 검증·후속 운영

악성 출력, 중복 키, 과도한 중첩/크기, 도구 호출, 입력 경계, busy/HTTP 실패 후 자원 반환을 fixture로 검사한다. 실제 CPU 모델은 합성 기사로 각각1회 호출했으며 결과는 [검증 증빙](../05-test/evidence/security-ai-oss-validation-20261031.json)에 기록한다. 이 소수 smoke는 일반 번역 성능·안전성 평가를 대신하지 않는다.

모델·실행기·의존성·프롬프트·주제 정책 변경 시 가드레일 회귀, 공급자 advisory, 고정 revision/SHA, 라이선스, 최종 이미지 검사를 다시 수행한다. 스캐너/고지 수집기의 성공을 모든 미공개 취약점 탐지나 법률 준수 보증으로 표시하지 않는다. CI/CD는 사용자 지시에 따라 구성하지 않았다.

근거: [OWASP LLM Top10 2025](https://genai.owasp.org/llm-top-10/), [EPL FAQ](https://www.eclipse.org/legal/epl-2.0/faq/), [Classpath 예외](https://spdx.org/licenses/Classpath-exception-2.0.html). 확인2026-10-31. 원문·해당 버전 고지와 프로젝트 노출 조건을 함께 검토했다.

## 6. 승인된 후속 G01~G11 보강 (2026-10-31)

현재 번역 모델 Index-Translate-2B와 분류 Qwen3.5-4B를 유지한다. 기존 A01~A06 검사 통과는 이후 발견한 결함까지 해결됐다는 의미가 아니다.

- G01: 수집 시 script/style/template/명시적 숨김 요소 제거. 기존 DB와 모델 어댑터 입력도 역할 표식·지시 덮어쓰기·제한적 Base64·반복을 검사해 자동 처리를 보류한다. 기사의 제목/링크와 원문 언어 fallback은 유지한다. 보안 연구의 인용도 보류될 수 있으며 악성 확정 판정이 아니다. 미지의 모든 주입 탐지를 보장하지 않는다.
- G02: 동일 모델의 /apply-template, /tokenize로 system/용어표/기사/템플릿을 포함한 실제 토큰 수를 계산한다. 입력+출력상한+64 여유가4096을 넘거나 검사가 실패하면 추론하지 않는다. 정책을 잘라 넣지 않는다.
- G03: 숫자/식별자/기존 방향 검사에 지원되는 명명 모델 간 우열 관계를 추가했다. 대상 뒤바꿈을 거부하고 검증 불가 비교 문장은 원문으로 종료한다. 전체 의미 동등성을 증명하는 검사는 아니다.
- G04: 명시 실행 scripts/test/model-guardrail-smoke.sh. 합성 공격6개 보류(추론0), 정상 번역/분류, 실제 실행 취소를 소수 호출로 구분한다. 모델 품질 보증과 다르다.
- G05: ai_source_budgets는 출처/모델/UTC날짜별 요청500, 입력300000자, 추론7200초를 원자적으로 제한한다. 시간은 최악 상한을 선예약하고 사용 시간을 정산한다. 자정이 지나도 예약 날짜 행에만 정산하며2일보다 오래된 집계를 정리한다. 회원/기사별 이용 기록은 만들지 않는다.
- G06: 갱신 실패/DB 오류/기한 초과 시 HTTP 스레드를 중단한다. 실제 비스트리밍 추론이 취소 후 계속되는 실패를 확인해 SSE로 변경했다. 텍스트 외 도구/역할·잘린 완료·중복 JSON·복잡도/전체바이트/문자/기한을 제한한다. 실제 취소 재검증 성공 전 완료로 집계하지 않는다.
- G07: translation_runtime의 DB lease로 worker 인스턴스 전체에서 한 건만 선점한다. lease와 기사 권리/잠금을 갱신·저장 시 재검사한다.
- G08: 번역은 전체20회/인프라8회/48시간으로 제한한다. 정상 health만으로 추론 오류 횟수를 지우지 않는다. 분류는3회/48시간으로 제한한다. 원문 변경/정책 변경은 새 처리 기준이다.
- G09: 프롬프트/어댑터/검증기/용어표/입력가드/토큰·SSE 파서의 실제 class bytes와 모델 revision fingerprint로 자동 결과를 구분한다. 구정책 번역/LLM태그는 조회 및 검색에서 제외한다. 관리자 잠금은 유지한다.
- G10: ADMIN+CSRF의 GET/PUT /api/v1/admin/translations/{articleId}/{ko|en}. 현재 내용 hash와 수정 version 충돌은409. 관리자 번역 잠금은 자동 upsert가 덮어쓰지 못한다. 기사 본문을 입력·보관하지 않는다.
- G11: Helm 모델 실행 Pod egress:[]; HF 다운로드는 비밀키 없는 별도 Job. runtime init은 체크섬 확인만 한다. 공유 RWO PVC는 model-volume label과 동노드 필수 affinity로 다운로드/실행을 맞춘다. lint/render/경계 검사와 실제 CNI 검증은 구분한다.

검사 중 Helm 기본값의 필수 digest 누락으로 Trivy가 chart를 건너뛰는 경고를 확인했다. 합성 digest로 렌더링한 전체 Kubernetes manifest를 별도 config 검사하고 미분석 시 gate가 실패하도록 보강했다.
