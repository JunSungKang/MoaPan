### 5.1 로컬 검증·보안

### 5.2 수동 배포·GitHub

공유 코드 변경은 위 순서로 진행한다. 외부 권한·출처 이용권·고위험 UNKNOWN은 해당 외부 동작을 차단하되 독립 구현은 계속한다. 각 단계의 상태는 PROGRESS와 ACCEPTANCE_MATRIX에 기록한다.

## 11. 공개 관심지면·권한별 메뉴·검색·약관 이력
### 11.1 기본 지면과 권한
최신 사용자 요청으로 비회원 실제 뉴스 금지를 제한 공개 지면으로 변경한다. 공개 GET은 최대30개/no cursor/전역 원자적 한도로 제한하고 기존 회원 quota/cursor는 유지. 관리자 공통 대표 관심사(DB singleton, version 충돌, ADMIN+CSRF+감사)를 비회원 및 관심사 미설정 회원에 적용. 회원별 관심사는 계속 브라우저만. 모든 정적 페이지/메뉴를 guest/USER/ADMIN으로 검사하고 보호 페이지 직접 접근도 제한한다.
### 11.2 화면과 이력
관심지면 하나로 통합, 검색/카테고리/날짜는 native dialog의 적용/취소/초기화로 로컬 처리. 약관은 판 번호만 표시하고 실제 Git에 존재하는 이전 본문을 정적 이력으로 제공하며 신규 동의 판을 갱신한다. 기존 동의 기록은 유지.
### 11.3 검증과 전달
공개 필드/상한/숨김 기사/권한/CSRF/충돌/기본값 및 메뉴 전체역할·검색 팝업·비전송·판 이력을 PostgreSQL와 Playwright Java로 검증. 기존 인수 기준의 변경 근거를 문서화. local 검사·이미지 검사·Compose 반영·HTTPS 확인·guarded push까지 진행한다. CI/CD/main merge/개인 관심사 서버 저장은 제외. 변경 경로 src/docs/scripts 및 현재 GitHub 계약 범위, 작업 루트는 승인된 moapan workspace만.

## 14. 실제 기술 동향 데이터 재구성
사용자 요청에 따라 worker 중지와 DB 트랜잭션으로 기존 기사·지면·연결 이력만 삭제하고 기존 출처를 중지한다. 회원·태그 사전·대표 관심사는 보존한다. 공식 이용조건과 robots를 검토한 새 RSS를 관리자 API로 등록하고 Java worker의 실제 성공 및 공개 지면을 확인한다. 코드는 변경하지 않으며 CI/CD·배포·기존 출처 재활성화는 하지 않는다. 결과와 제외 후보를 docs에 남기고 기존 guarded branch로 전달한다.

## 15. 주제·날짜 제한과 논문 수집
### 15.1 구현
관리자 수집 주소에 발행 시작일(Asia/Seoul, 해당 날짜 포함)과 제목/설명 키워드 OR 필터를 추가한다. 발행일 미상은 날짜 필터에서 제외한다. 논문은 arXiv 검색 API의 카테고리·제목/초록·제출일 검색을 이용하고 메타데이터만 저장한다. JSON 루트 배열과 arXiv의 공식 HTTP 링크를 HTTPS 링크로 정규화하는 제한적 호환성을 지원한다. 기존 기사 삭제는 추가 요청하지 않았으므로 조건 밖 기존 데이터는 비공개 처리한다.
### 15.2 검증
경계 날짜·미상/미래 시각·부분 문자열·필터 변경 후 캐시 무효화·미리보기/worker 일치·JSON 배열·Atom 테스트. 실제 허용 출처 등록·조건에 맞는 수집·공개 결과 검증. JAR/이미지 검사 후 현재 Compose 반영, 문서 증빙과 guarded push.

## 16. 카드 원문·한국어 번역 전환
### 16.1 표시·데이터
영문 제목과 추출 요약을 보존하고 카드 단위 원문/한국어 전환을 제공한다. 번역은 기사 공통 데이터이며 회원 관심사·검색어·클릭을 번역 엔진에 보내지 않는다. 번역 결과는 입력 내용과 연결하여 원문 변경 시 오래된 번역을 제공하지 않는다. 출처 번역 허용과 자동 번역 표시를 적용한다.
### 16.2 엔진·검증
브라우저 전용 번역은 모바일 미지원으로 주 구현에서 제외한다. 로컬 모델 또는 공식 API 방식에 대한 사용자 선택을 요청했다. 현재 엔진 미연결이며 실제 번역·공개 반영은 미완료다. UI 전환·실패·원문 보존·권리 철회·입력 변경 테스트 후 산출물 검사와 Compose 반영, guarded commit/push를 수행한다. 승인 workspace 안에서만 파일을 작성한다.

## 17. 카드 여섯 항목과 R&D 중심 추출 요약
### 17.1 구현
제목(원문 링크), 작성일(제공된 발행일), 작성자, 출처, 주제(분류 태그), R&D 요약만 카드에 표시한다. 작성일·작성자 미제공은 정보 없음으로 표시하며 수집 시각/기관명을 대신하지 않는다. Atom/RSS 작성자와 제한 JSON author 매핑을 영속화한다. 연구 문제·방법·평가·한계 및 취약점 영향/대응 관련 원문 문장을 우선 추출한다. 자동 해석·번역·확인되지 않은 연구 의의는 생성하지 않는다. 이전 번역 모듈 초안은 보존하되 카드에는 연결하지 않는다.
### 17.2 검증·전달
파서 작성자/해시 변경, 요약 근거/우선순위/잠금, 공개 DTO, 회원/비회원 카드 구성과 반응형 테스트. 기존 허용 출처를 재수집하여 데이터 갱신. 산출물·이미지 검사 후 Compose 반영 및 guarded push. 회원 데이터와 수집 권리 범위는 변경하지 않는다.
